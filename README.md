# JobPilot AI

AI-powered Job Assistant Agent

---

## Introduction

JobPilot AI is an intelligent job assistant powered by LLM.

It can:

- Parse resumes
- Analyze Job Descriptions
- Optimize resume content
- Generate interview questions
- Match resumes with target jobs
